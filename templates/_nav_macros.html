{% import "_ui_macros.html" as ui %} {# Macros de navigation partagées par les deux coquilles (_coquille_onglets.html et _coquille_laterale.html). À importer avec « with context » : elles lisent la variable `path` posée par base.html, sans qu'on ait à la passer en argument. Le paramètre `icon` est un NOM du jeu d'icônes (voir _icones.html), pas un emoji : c'est la macro qui produit le SVG. Le calcul d'`active` est volontairement identique aux trois : `path == href`, ou `path` sous l'arborescence de `href`. Le test `href != '/'` évite que l'onglet « Candidats » (/) reste actif sur toutes les pages. #} {# Onglet horizontal (coquille « onglets »). #} {% macro onglet(href, label) %} {% set active = (path == href) or (href != '/' and path.startswith(href ~ '/')) %} {{ label }} {% endmacro %} {# Entrée d'un menu déroulant (menu utilisateur / administration). #} {% macro entree_menu(href, icon, label) %} {% set active = (path == href) or (href != '/' and path.startswith(href ~ '/')) %} {{ ui.ic(icon) }}{{ label }} {% endmacro %} {# Lien de la barre latérale (coquille « lateral »). #} {% macro lien_lateral(href, icon, label) %} {% set active = (path == href) or (href != '/' and path.startswith(href ~ '/')) %} {{ ui.ic(icon) }}{{ label }} {% endmacro %}
