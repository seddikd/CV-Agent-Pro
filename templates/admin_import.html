Un fichier PST/OST est un instantané : l'import parcourt ses messages une fois et réutilise le pipeline habituel (détection de CV, extraction, dédup). Les messages sans pièce jointe PDF/DOCX sont ignorés. Réimporter le même fichier ne crée pas de doublons. Suivi et résultats dans Cycles.

{{ ui.ic('ampoule') }} Après un import, le bouton « {{ ui.ic('dossier') }} Ranger les traités » déplace les mails porteurs d'un CV vers un dossier (par défaut Traités) pour garder la boîte propre. Cette écriture nécessite Outlook installé (backend win32com) ; indisponible avec le seul lecteur pypff (lecture seule).
• .pst : déplacement dans le fichier, sans effet sur le serveur.
• .ost : un OST est le cache d'un compte Exchange/Microsoft 365 et ne peut pas être monté seul — l'opération s'applique à la boîte réelle du compte (le compte doit être configuré dans Outlook sur ce poste) et se synchronise vers le serveur.
